About me

I’m Arifur, a software engineer who turns messy business processes into clean, reliable tools. Most of my work sits between a Python back end and a lightweight, server-rendered front end.

I prefer HTMX over heavy JavaScript frameworks when the job allows it: fewer moving parts, faster pages and code that is easy to hand over. Excel is still part of many teams’ daily work, so I build tools that read, clean and produce spreadsheets people already trust.
